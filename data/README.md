# Data codebook

Synthetic. Generated by `scripts/make_data.py` from `src/psychsim/simulate.py` with a fixed seed, so the
true parameters are known and stored here. The committed files are the ones the notebook, the talk and
the agent runs use. Re-running `make_data.py` reproduces the participants and the session accuracies
exactly; the trial-level coin flips were drawn by an earlier version of the simulator, so some
`n_correct` values come out different.

| File | One row per | Columns |
|---|---|---|
| `sessions.csv` | participant × session × condition | `participant` (1–40), `session` (1–5), `condition` (`standard` / `hard`), `n_trials` (100), `n_correct` |
| `trials.csv` | trial | `participant`, `session`, `condition`, `trial` (1–100), `correct` (0/1) |
| `truth.json` | — | `mu`, `beta`, `sigma_participant`, `kappa`, `sd_between_sessions`, `seed`, sizes |
| `truth_participants.csv` | participant | `theta` (logit-scale ability), `p_standard`, `p_hard` |
| `truth_sessions.csv` | participant × session × condition | `p_true` (the session-level accuracy the trials were drawn from) |

Generative story: participant ability `theta_i ~ Normal(mu, sigma_participant)` on the logit scale; the hard
condition shifts it by `beta`; each session's accuracy is drawn from a Beta around the participant's
mean with concentration `kappa`; trials are Bernoulli draws from that session accuracy.
